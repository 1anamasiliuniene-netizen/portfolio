# Ana Masiliuniene Portfolio

A personal UX design and research portfolio built with Django. The site presents selected case studies, a professional profile, a downloadable resume, and contact links in a calm editorial interface.

## Project Overview

This portfolio is designed to show the full path from research and product thinking to implemented digital experiences. It combines long-form case studies with practical project details, including live application links, source code links, responsive previews, and structured design process documentation.

The content focuses on UX research, interaction design, systems thinking, and frontend craftsmanship.

## Main Sections

- **About:** professional background, design principles, career journey, publication links, and contact options.
- **Case studies:** selected product work with project summaries, visual previews, table-of-contents navigation, and detailed process sections.
- **Resume:** downloadable active resume, professional statement, and optional downloadable certificates.

## Featured Case Studies

### A Terapija

A digital wellbeing platform created for a real practice owner. The case study covers discovery, user research, information architecture, user flows, UX decisions, design system work, Django implementation, outcomes, and reflection.

### Mini Notion

A productivity and project-management case study focused on dashboard structure, task workflows, information hierarchy, research findings, design proposals, and interface refinement.

## Content Management

The portfolio includes admin-managed content for:

- Published projects and project ordering
- Project preview images
- Live application and source code links
- Case study sections and expandable content
- Active resume document
- Additional certificates
- About page contact links

This keeps public content editable without changing page templates for routine updates.

## Design Direction

The interface uses quiet typography, generous spacing, structured editorial layouts, and expandable detail sections. The goal is to make long-form UX case studies readable while keeping key actions, project navigation, and downloadable documents easy to find.
